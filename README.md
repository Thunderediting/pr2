# Functional Threat

A Python-based data analysis and transformation utility focused on clarity, practicality, and strong fundamentals in software development.

## Overview

This project demonstrates a clean, beginner-friendly approach to working with numerical data in Python. It allows users to input a dataset, inspect summary information, apply transformations, and calculate key statistics using built-in Python functions and core programming concepts.

## Code Ideology

My development philosophy is grounded in writing software that is:

- Readable first: code should be easy to follow, understand, and maintain.
- Practical: solutions should solve real problems without unnecessary abstraction.
- Pythonic: I value natural, concise patterns that use the language effectively.
- Minimal but robust: simple logic, clear structure, and dependable behavior over complexity.
- User-oriented: software should be intuitive, helpful, and accessible.

This project reflects that belief by emphasizing straightforward logic, reusable functions, and a command-driven interface that gives users immediate feedback.

## Project Purpose

The application acts as a lightweight data analyzer and transformer with the following capabilities:

- Input a 1D array of integers
- Display a basic summary of the dataset
- Compute factorial values using recursion
- Filter values based on a threshold using a lambda function
- Sort the data in ascending or descending order
- Calculate essential statistics such as maximum, minimum, sum, and average

## Technical Highlights

- Uses Python lists as the core data structure
- Implements iterative menu-driven interaction
- Demonstrates recursion for factorial calculation
- Applies functional programming concepts with `filter()` and `lambda`
- Uses built-in functions like `sum()`, `max()`, `min()`, and `sorted()`
- Incorporates reusable helper logic for dataset statistics

## Example Workflow

1. Select option 1 to enter data
2. Select option 2 to view a dataset summary
3. Select option 3 to calculate a factorial value
4. Select option 4 to filter values above a threshold
5. Select option 5 to sort the dataset
6. Select option 6 to view statistical insights
7. Select option 7 to exit the program

## How to Run

From the project directory, run:

```bash
python pr2.py
```
